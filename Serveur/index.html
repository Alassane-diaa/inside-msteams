🔒 Serveur HTTPS avec SSLKEYLOGFILE

✅ Statut du serveur

Le serveur HTTPS fonctionne correctement !

Connexion sécurisée établie via TLS/SSL

📋 Informations

  • Protocole: HTTPS (HTTP over TLS/SSL)
  • Port: 4443
  • Certificat: Auto-signé (localhost)
  • Capture des clés: Activée (SSLKEYLOGFILE)

🔑 Capture des clés TLS

Les clés de session TLS sont enregistrées dans server_keys.log

Utilisez ce fichier avec Wireshark pour déchiffrer le trafic HTTPS capturé.

Configuration Wireshark:

  1. Edit → Preferences → Protocols → TLS
  2. (Pre)-Master-Secret log filename: server_keys.log
  3. Le trafic HTTPS sera automatiquement déchiffré

🧪 Tester avec curl

Pour tester et capturer les clés côté client:

$env:SSLKEYLOGFILE = "client_keys.log"
curl -k https://localhost:4443/
