# Inside MS Teams — Journal de bord (Projet 2A Mines Nancy)

## 🎯 Objectif
Ce projet a pour but d’explorer le fonctionnement interne de Microsoft Teams dans une démarche **strictement pédagogique**, encadrée par un enseignant.  

## 🧠 Contexte
Ce travail s’inscrit dans le cadre du projet de 2ᵉ année du département informatique à l’École des Mines de Nancy (FICM).  

## 🗓️ Organisation du travail
Le dépôt sert de **journal de bord**, documentant chaque étape de l’analyse :
- découvertes techniques,  
- hypothèses de fonctionnement,  
- résultats d’observation,  
- réflexions à présenter à l’encadrant.
